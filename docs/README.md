## The window in one minute

On top you switch between **Work** and **Studio**.

- **Work** is where the team works: **Hive**, **Project**, **Ask**, **Git**, **Test**, **Mockups**, **Phone** and **Ship**.
- **Studio** is where you make the team: **Overview**, **Brief**, **Design**, **Build**, **Reports** and **Passport**.

The top bar shows what the project has cost, your License, Remote, Help and the Model menu. **VS Code**, **Terminal** and **Finder** open the project folder in those apps.

## Words

- **Bee:** one AI agent of the team, with one job.
- **Hive:** the team at work on a task.
- **El Capitan:** the leader of the team. It gives each bee its work in order and checks the results.
- **Kukulu:** the builder bee. It designs and builds the team with you.
- **Chain:** the order in which the bees work, with the checks and the ways back.
- **Run:** one task of the team, from start to end.
- **Session:** one talk with El Capitan, on one git branch.
